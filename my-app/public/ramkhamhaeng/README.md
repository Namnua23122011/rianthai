# Card images

Provided by the user in `ก (1).zip`. Images were resized proportionally to fit
600 × 800 pixels and converted to JPEG for the browser. The original ZIP is unchanged.
Image numbers preserve the original filenames.

- `1.jpg`: shared card back, as requested.
- Pair mappings: `src/matchingCards.js`.
- `32.jpg` and `33.jpg`: alternative ancient forms paired with `34.jpg` (ฐ),
  both accepted by the user. One is randomly selected for each round.
- `24.jpg`, `35.jpg`, `37.jpg`, `85.jpg`, `89.jpg`: dash placeholders for
  ฌ, ฑ, ฒ, ฬ, ฮ. These five pairs are excluded from play.
- All 90 supplied images are retained; 39 complete letter pairs are playable.
